# Auralis identity

An original three-stroke signal aperture: distinct paths, shared direction. The wordmark pairs a quiet, spacious silhouette with a precise ascending rhythm.

## Assets
- `icon-light.svg`, `icon-dark.svg`: theme-specific square app/avatar marks.
- `wordmark-light.svg`, `wordmark-dark.svg`: transparent horizontal lockups; use the asset matching its background.
- `readme-header-light.svg`, `readme-header-dark.svg`: repository cover artwork.
- PNG icons at 32, 128, 512 and 1024 pixels for previews and reuse. Native launcher assets live in each platform project.

## Palette
Ink #071A21; mint #84E4CA; light canvas #F4F8F6; deep teal #176B5B. Use mint on ink and deep teal on the light canvas. Status must always include text or an icon, never color alone.

## Usage
Keep clear space of one stroke-height around the symbol. Do not stretch, add shadows to the mark, use gradients inside its strokes, or substitute the brand mark for an actionable control. Minimum icon size: 24 logical pixels. Respect device accessibility text scaling and reduced motion.

This is original repository-native vector artwork. It is not evidence of trademark clearance or native app screenshot validation.
